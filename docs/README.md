# Guía educativa de EconoMina

> EconoMina es un simulador educativo. No reemplaza una evaluación económica profesional, un estudio de factibilidad, una valorización de reservas, un modelo financiero auditado ni la aprobación de un proyecto minero real. Ningún resultado constituye una recomendación de inversión.

## Usuario objetivo

| Aspecto | Descripción |
|---|---|
| Carrera | Ingeniería de Minas |
| Ciclo sugerido | 6.º a 10.º ciclo (economía minera, evaluación de proyectos, planeamiento) |
| Conocimientos previos | Matemática financiera básica, nociones de leyes y recuperación |
| Necesidad | Conectar las variables técnicas del yacimiento con la evaluación económica |

## Competencias que desarrolla

1. Estimar costos de capital y de operación, y expresarlos por tonelada y por unidad de metal.
2. Calcular metal contenido, metal recuperado, ingresos y margen operativo.
3. Interpretar la ley de corte y su dependencia del precio, la recuperación y los costos.
4. Construir un flujo de caja anual y calcular VAN, TIR y periodo de recuperación.
5. Identificar las variables críticas mediante escenarios y análisis de sensibilidad.
6. Argumentar una decisión educativa (continuar, estudiar más o no continuar) bajo supuestos explícitos.

## Recorrido sugerido

1. **Inicio**: lee la advertencia académica y revisa el proyecto activo.
2. **Datos del proyecto** y **Costos**: modifica los datos y observa los mensajes de validación.
3. **Ley de corte**: compara el método de equilibrio con el marginal.
4. **Producción e ingresos** → **Flujo económico** → **VAN** → **TIR**: sigue el camino del mineral al valor.
5. **Sensibilidad**: identifica la variable que más mueve el VAN.
6. **Casos empresariales**: decide antes de ver la solución.
7. **Evaluación práctica**: responde preguntas y resuelve ejercicios numéricos generados; revisa la solución paso a paso.
8. **Tutor económico**: consulta dudas; las respuestas se adaptan al proyecto activo.

## Actividades para el docente

- Pedir que el estudiante encuentre el precio que vuelve el VAN igual a cero en el proyecto base.
- Comparar el caso de alta ley (subterráneo pequeño) con el de baja ley (gran escala).
- Discutir por qué el caso sensible al precio tiene VAN base positivo pero riesgo medio.
- Comparar el margen de seguridad del precio entre los seis casos (módulo VAN tras cargar cada caso).
- Usar la práctica numérica como evaluación formativa: cada intento genera datos nuevos.
- Activar impuestos y explicar la diferencia entre flujo antes y después de impuestos.

## Diferenciación frente a métodos tradicionales

| Método tradicional | Limitación | Aporte de EconoMina |
|---|---|---|
| Apuntes o PDF | Fórmulas aisladas | Cada fórmula se aplica al mismo proyecto y se ve su efecto |
| Hoja de cálculo | Requiere construir el modelo | Modelo listo, validado y con explicaciones |
| Video | Aprendizaje pasivo | El estudiante cambia datos, decide y recibe retroalimentación |
| Ejercicio en clase | Un único escenario | Escenarios y sensibilidad inmediatos |

## Uso sin conexión y progreso

La aplicación no requiere internet, no crea cuentas y no envía datos a terceros. El proyecto activo, el escenario, los casos resueltos y los mejores puntajes se guardan **solo en el dispositivo** y pueden reiniciarse desde la pantalla de inicio.
